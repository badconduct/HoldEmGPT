# The Empty Chair: house-supplied evidence dossiers

Read the records before opening [the separate solutions](story-solutions-v4.md). These packets reproduce the complete HTML comparison text and witnessed source labels, without private predicates or a visible guilty flag. They are ready for a fresh reader; automated consistency checks do not establish human difficulty.

The established private-door account identifies the responsible host: the sole visitor alone with the victim in a genuine killing, or the arranger of a staged scene. Exactly one exhibit has an incorrect comparison. A true shortlist preserves all remaining alternatives, not multiple visitors. The other four exhibits must all hold. Every necessary fact is supplied as text.

Each sealed packet is supplied under its own house boss's authority. The responsible boss supplied the one false exhibit; all four other houses supplied truthful records. The circuit clerk witnessed the transfers and confirms these source labels, even when an acting steward handed over a packet.

Each case has 24 possible delivery assignments. These packets show one fixed valid assignment. Each of the four truthful records supplies an indispensable incident-room exclusion. Omitting any one leaves another hotel possible, even after identifying the false supplier. The final accusation requires all five deliveries and names the exhibit set aside.

A gunshot must fit a projectile; a narrow stab must fit a blade; a blunt blow can fit the ashtray or bottle; strangulation must fit a cord. Damaged copied reports may retain alternative readings.
