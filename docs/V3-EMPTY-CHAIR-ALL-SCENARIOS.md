# Empty Chair: all 150 scenario assignments

Generated by scripts/build-v3-case-matrix.mjs. Author-only solutions; not deployed game content.

125 murder setups (5 bosses x 5 hotels x 5 false categories) + 25 staged-death setups (5 bosses x 5 hotels, photograph false). Each row assigns five exhibits; [FALSE] marks the one false claim. This covers the high-level setups with one proposed bundle each, not every possible permutation of all 25 exhibit forms.

**Validation scope:** complete coverage, exactly one false item per row and unique boss/hotel matching of abstract item references passed. These references use an artificial assignment pattern. Real clue wording, evidence comparisons and murder-versus-staging deduction remain unvalidated. Do not turn the pattern itself into a player puzzle.

Object names identify reusable art forms, not the complete clue. See the accompanying JSON for each claim, correction, award location and required writing. The ordinary murder rows include false photographs too, so a false photo does not automatically mean a staged death.

The [evidence flow and endings specification](V3-EVIDENCE-FLOW-AND-ENDINGS.md) defines the 25 image briefs, reveal scenes, bag and three-answer finale (responsible boss, hotel, actual weapon or staged death). Success retains cash and opens continued poker; failure forfeits this campaign's cash and makes its protagonist the next linked campaign's victim. Successor-victim cases require validated motive/description adaptations; these base rows are not completed scripts for that rule.

Every character opens with a suitcase, exactly $1,000 and the same fixed letter. A failed ending ambiguously closes on those same objects, then The End and the main menu. The next-victim link is revealed later in the next campaign's case briefing, not announced in the ending. The closing suitcase does not credit the failed character's wallet.

## Interpretation and remaining work

- A staged death has no actual murder weapon; its recovered prop is genuine. Only the photo's death claim is false.
- Receipts can be from another house. Their cashout location is not automatically the crime location.
- Exhibit awards are distributed one per casino; their source house does not identify the culprit or forgery author.
- Boss-victim cases require a house representative at the poker table. This is not implemented in the current game.
- [FALSE] may mean altered attribution or an inaccurate core claim rather than a physically nonexistent object.
- Case creation must preserve its assignments through retry/save/load. Dialogue is optional and never supplies a required sixth clue.
- The 150 rows are coverage targets, not 150 finished scripts. Complete and human-test at least one paper case before turning the whole catalog into game content.
